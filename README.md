### 🤖 AI Resume Matcher — Enterprise Edition
**`FastAPI · Next.js 14 · BERT · PostgreSQL · Redis · Docker`**

An AI-powered resume intelligence platform that scores, rewrites, and optimizes resumes against job descriptions — built for job seekers and enterprise HR teams alike.

**ML Pipeline:**
- 📄 PDF/DOCX parsing with OCR fallback via pdfplumber
- 🔍 spaCy NLP keyword extraction + skill alias resolution
- 🧠 BERT semantic scoring via sentence-transformers
- 📊 TF-IDF lexical matching + OpenRouter LLM evaluation
- ⚖️ Role-weighted scoring across 10 job family profiles

**Architecture:**
- ⚡ FastAPI async backend with SQLAlchemy 2.0
- 🔄 Celery 5 workers for async ML pipeline execution
- 🔐 JWT auth with refresh token rotation
- ☁️ Docker + docker-compose · CI/CD via GitHub Actions
